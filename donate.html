Why this project exists

As a postdoc working in a wet lab, I kept copying data between Excel and graphing software just to make simple figures — bar plots, box plots, dose-response curves. The data was already in Excel. The only missing piece was the visualization.

Figra started as a personal script and grew into a full Excel add-in that runs R and ggplot2 entirely in the browser — no installation, no subscription. If it helps other researchers spend less time on figure formatting and more time on science, that's the goal.

— Yoshiaki Sato, postdoctoral researcher
