For IT Administrators — Centralized Deployment

If your organization restricts Microsoft AppSource, you can deploy Figra to your users centrally via the Microsoft 365 Admin Center. Once deployed, Figra appears automatically in Excel for all assigned users — no individual installation needed.

Deployment Steps

  1. Sign in to Microsoft 365 Admin Center
  2. Go to Settings → Integrated Apps → Upload custom apps
  3. Select "Provide link to manifest file" and paste:
    https://h20gg702.github.io/figra-pages/manifest.xml
  4. Choose the scope: all users, specific groups, or specific users
  5. Click Deploy

Security & Privacy

  • All computation runs entirely in the user's browser via WebR (R in WebAssembly) — no data is sent to any external server
  • Figra only reads data from the active Excel workbook (requires ReadWriteDocument permission to insert figures)
  • Figra is listed on Microsoft AppSource and has been reviewed by Microsoft
  • Source code is publicly available at github.com/h20gg702/figra-pages
